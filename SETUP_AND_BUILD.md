# Настройка и пересборка APK (Voice Assistant)

**Picovoice больше НЕ нужен** — ни регистрации, ни ключей. Кодовое слово
детектируется той же моделью Vosk, что и распознавание команд. Всё 100%
бесплатно и офлайн.

Инструкция для проекта `VoiceAssistant/`. Весь процесс — ~10 минут.
Нужен компьютер с **Android Studio** (или JDK 17 + Android SDK для CLI).

---

## Шаг 1. Скачать модель Vosk (~5 мин, ~46 МБ) — единственный обязательный шаг

1. Скачайте русскую модель:
   https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
2. Распакуйте архив — внутри папка `vosk-model-small-ru-0.22`.
3. Переместите ЭТУ ПАПКУ в `VoiceAssistant/app/src/main/assets/vosk/`
   (папку `vosk` создайте, если её нет).

Итог — должен существовать путь:
```
app/src/main/assets/vosk/vosk-model-small-ru-0.22/am/final.mdl
```
Имя каталога обязано совпадать со значением `VOSK_MODEL_ASSET_DIR` в `Config.kt`.

---

## Шаг 2. Кодовое слово (по желанию)

По умолчанию настроены слова **«джарвис» / «jarvis» / «computer»** — ничего
менять не нужно. Список настраивается в одном месте:

`app/src/main/java/si/unisa/sss/pocketvoiceassistant/Config.kt`:
```kotlin
val WAKE_KEYWORDS: List<String> = listOf("джарвис", "computer", "jarvis")
// например: listOf("внимание", "компьютер", "алиса")
```
Регистр не важен. Совет: берите редкие, чётко произносимые слова — меньше
ложных срабатываний (детектор слушает микрофон постоянно и может реагировать
на фоновую речь).

---

## Шаг 3. Сборка APK

**Android Studio:** File → Open → выбрать папку `VoiceAssistant/` → дождаться
синхронизации Gradle → Build → Build App Bundle(s)/APK(s) → Build APK(s).
Файл: `app/build/outputs/apk/debug/app-debug.apk` (кнопка locate в уведомлении).

**Командная строка:**
```bash
cd VoiceAssistant
./gradlew assembleDebug        # Windows: gradlew.bat assembleDebug
```

Если ругается на SDK — откройте Project Structure и укажите путь к Android SDK
(создастся `local.properties`), либо экспортируйте `ANDROID_HOME`.

---

## Шаг 4. Установка на телефон

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
Или просто скопируйте APK на телефон и откройте его (разрешите установку из
неизвестных источников).

---

## Шаг 5. Проверка работоспособности

1. Запустите приложение → разрешите доступ к микрофону.
2. Первый запуск: «Загрузка модели распознавания…» — 1–3 минуты
   (модель копируется из assets; при следующих запусках — секунды).
3. Появится статус «Слушаю кодовое слово…». Скажите **«Джарвис»**.
4. Ассистент ответит тоном ожидания → скажите фразу, например
   «сколько времени» → через пару секунд он повторит распознанный текст вслух.
5. В фоне работает уведомление «Фоновое прослушивание активно» — приложение
   можно свернуть, конвейер продолжает работать.

## Известные ограничения MVP

- Wake-word через STT-модель чувствителен к фоновой речи (возможны ложные
  срабатывания). Для продакшена вернём специализированный детектор
  (Snowboy-аналог / Porcupine без ключа нельзя — но есть open-source варианты).
- Постоянно открытый микрофон расходует батарею; Android может требовать
  разрешение на фоновый запуск (в настройках приложения выберите «Без ограничений»).
- Ответ ассистента — заглушка (эхо): текущий этап проверяет конвейер
  wake → STT → TTS, а не логику ассистента.

## Частые ошибки

| Ошибка | Решение |
|---|---|
| `VOSK_MODEL_ASSET_DIR ... not found` | Папка модели в assets названа иначе, чем в Config.kt — выровняйте имена |
| Тишина после кодового слова | Не выдано разрешение RECORD_AUDIO; переназначьте в Настройки → Приложения |
| Не собирается: `SDK location not found` | Откройте проект в Android Studio один раз — она создаст local.properties |
| Срабатывает на любую речь | Уменьшите список/замените WAKE_KEYWORDS на более редкое слово |
